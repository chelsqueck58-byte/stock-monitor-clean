# Stock Monitor - Clean Deployment

Live version: https://chelsqueck58-byte.github.io/stock-monitor-clean/

## Layout

- **Summary Tab**: Upcoming and past catalysts + market indices
- **Sector Tabs**: China Internet, AI & Big Tech, Semis, China EV, Singapore, SE Asia Tech, Consumer  
- **History Tabs**: Past Month events + Per-stock price moves

## Data Files

- `index.html` - Main website  
- `data.json` - Stock/catalyst data  
- `moves.json` - Historical price moves  
- `vendor/` - Chart library (Lightweight Charts)
